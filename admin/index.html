Quản lý dự án

Đăng game mới hoặc thay video, bản chơi thử. Mỗi game có một link riêng để gửi cho publisher, không hiện trên trang chủ.

1. Kết nối GitHub

  1. Mở trang tạo token (Fine-grained token).
  2. Đặt tên tùy ý, Expiration chọn thời hạn (ví dụ 1 năm).
  3. Repository access → Only select repositories → chọn portfolio.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Bấm Generate token, copy rồi dán vào ô dưới. Token chỉ lưu trên trình duyệt này.
